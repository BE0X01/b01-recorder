# B01 Recorder v0.3

- Fixed stale rounded borders and resize redraw artifacts.
- Consolidated settings into three compact sections, with no settings scrolling at the minimum 900 × 650 window size.
- Moved external playback, folder access, and deletion into the More menu; removed redundant FPS preset controls.
- Remember window size, position, and maximized state across restarts. Recover off-screen windows onto a connected display.
- Added customizable recording filenames, a live example, and an information icon with date/time tag help. Default: `record_%y%m%d-%n` → `record_261014-01.mp4`.
- Automatically choose available numbers and prevent overwriting existing files. Custom recording names are discovered in the recording library.
- Updated the README preview with a fresh screenshot of the compact interface.

## Download and setup

Download **b01-recorder-v0.3-win-x64.zip**, extract it, then run **Install-FFmpeg.cmd** before launching **b01-recorder.exe**. The installer downloads FFmpeg directly from its supplier and verifies the pinned SHA-256. FFmpeg and FFprobe binaries are not included in the release ZIP.

Windows 10/11 x64. The .NET runtime is included. In-app previews require Microsoft Edge WebView2 Runtime. Included components retain their own licenses; see THIRD-PARTY-NOTICES.md and the licenses folder.
